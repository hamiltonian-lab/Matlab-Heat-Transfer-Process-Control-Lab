# Contributing

This is an evolving educational laboratory prototype. Before opening a pull request, please:

1. Open an issue or discuss the change with the maintainer, especially if it affects hardware output commands, timing, networking or arming.
2. Keep hardware-independent simulation and HTTP transport logic clearly separated from Modbus output actions.
3. Never add live access codes, station history, institutional credentials, identifying student data or private network information.
4. Describe how you verified changes (static tests, offline simulation, isolated low-voltage bench checks, or commissioned hardware tests); do not claim hardware validation from software-only tests.
5. Update associated documentation for changes to model formulas, exported data or control behavior.

No open-source license is present pending ownership/approval review; please contact the maintainer before submitting substantive contributions.
