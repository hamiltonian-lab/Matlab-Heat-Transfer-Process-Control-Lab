# Student CSV exports

The student browser provides separate export links according to the active tab. Python reads the station's CSV generated by MATLAB; it does not recompute control terms.

## Simulation view

`/api/export.csv?mode=simulation` → `stationN_simulation.csv`

| Column | Meaning |
|---|---|
| `SimulationElapsed_s` | Cumulative simulated runtime |
| `DigitalTwin_C` | Current virtual vessel temperature |
| `Setpoint_C` | Shared station setpoint |
| `SimPID_Duty_pct` | Virtual heater command (0–100%) |
| `SimP_pct` | Simulation P contribution |
| `SimI_pct` | Simulation I contribution |

## Live experiment view

`/api/export.csv?mode=live` → `stationN_live.csv`

| Column | Meaning |
|---|---|
| `LiveElapsed_s` | Cumulative live PID runtime |
| `Measured_C` | WIKA-scaled measured temperature |
| `Setpoint_C` | Shared station setpoint |
| `LivePID_Duty_pct` | Live calculated duty |
| `LiveP_pct`, `LiveI_pct`, `LiveD_pct` | Live PID contributions |

An internal combined history file (`stationN_history.csv`) is also written to the runtime directory; the student links do not use it by default.

## Important current implementation behavior

- MATLAB retains only the **latest 400 rows** per station (`s.history`). Exports are short rolling histories rather than entire experiments.
- Rows are currently appended each timer tick, whether or not the corresponding mode is running. The exported files have **mode-specific columns**, but may contain periods where that mode is stopped, including repeated elapsed times and stale/zero values.
- The station setpoint and base PID gains are currently shared across simulation and live modes.
- A simulation reset clears the shared history buffer for that station.
- No dedicated export endpoint exists for the tuning tab; the browser currently points it to the simulation export.

For a publication-grade dataset, implement mode-specific recording windows, run IDs, absolute timestamps, units/calibration metadata, full-duration capture, and unambiguous state flags.
